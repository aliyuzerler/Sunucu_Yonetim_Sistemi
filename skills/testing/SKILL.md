# Skill: Test Engineering

Write unit, integration, contract, security-negative and E2E smoke tests. Make tests deterministic and safe; use mocks or disposable VMs/containers. Verify failure states, timeouts, retries, duplicate delivery, cancellation, stale capabilities and compatibility mismatch. A phase passes only when all acceptance criteria have evidence. Clearly separate not-run, blocked, failed and passed. Never report a test passed when it was skipped.
