# Skill: KVM / libvirt Virtualization

Use libvirt API and typed VM lifecycle operations. Detect hardware virtualization, kernel modules, storage pools, bridges and host capabilities. Separate VM definition, disk image, network and guest agent lifecycle. Validate CPU/RAM/disk quotas and prevent host path escapes. Distinguish VM creation from guest OS management: a guest requires its own Agent for in-guest services. Test create/start/stop/snapshot/restore/delete and failed provisioning in disposable hosts.
