# Skill: Security Review

Review trust boundaries, RBAC, node scope, agent identity, secret handling, input validation, file paths, command construction, Docker/KVM privilege, SSRF, CSRF, replay, idempotency and audit. Attempt negative cases, not only happy paths. Report severity, reproduction, impact and remediation. Critical/High unresolved issues block release. Never test destructively on production without explicit authorization and rollback plan.
