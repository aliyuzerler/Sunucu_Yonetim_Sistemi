# Skill: Docker Management

Use Docker Engine API with version negotiation and least-privilege design. Treat daemon access as host-root-equivalent. Never expose the socket to browser/public network. Validate image references, Compose schema, bind mounts, capabilities, privileged mode, host namespaces, devices and published ports. Preview changes and require explicit confirmation for destructive operations. Do not execute untrusted Compose content without policy checks and resource limits. Integration tests use disposable Docker hosts.
